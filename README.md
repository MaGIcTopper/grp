# ⚖️ SMJ Handbook — Рабочий справочник Великокельветского государства

Справочник по законодательству ГРП (Германия РП): Уголовный кодекс (4 уровня), Процессуальный кодекс (Statescode of Procedure), Положение о Государственном министерстве юстиции, Указы Офиса Канцлера и Офиса Лидера, юрисдикции полицейских структур и территориальные режимы.

🔗 **Сайт:** https://magictopper.github.io/grp/

## 📜 Правовая основа

Справочник составлен на основе:
- Положения о Государственном министерстве юстиции,
- Statescode of Procedure (SMJ),
- Statescode of Crimes (SMJ),
- Указов Офиса Канцлера и Офиса Лидера Великокельветского государства.

Материал носит информационно-справочный характер. Перед принятием процессуального решения сверяйся с действующей редакцией нормативных актов.
